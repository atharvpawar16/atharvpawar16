# Atharv Pawar

Self-taught full-stack developer from India. I'm also a third-year B.Com student, so I tend to build things that sit somewhere between software and everyday paperwork.

I like projects that stay up and stay simple, and I build them on free tiers.

## What I've built

- **[GlobalPulse](https://github.com/atharvpawar16/GlobalPulse)** - a live world-events dashboard. It reads 40+ news and alert feeds, sorts events by type, and pins them on a satellite map. ASP.NET Core, SignalR, PostgreSQL, Leaflet. [Live](https://globalpulse-mdmw.onrender.com)
- **[ADP Chathouse](https://github.com/atharvpawar16/adpchathouse-app)** - an Android group chat with a terminal look. No phone number needed, Firebase behind it. [Web version](https://atharvpawar16.github.io/adpchathouse-app/)
- **[APDocs Studio](https://github.com/atharvpawar16/APDocsStudio)** - a Windows photo and PDF editor with OCR, built on the open-source NAPS2. [Site](https://apdocsstudio.netlify.app/)
- **[Fog Mirror](https://github.com/atharvpawar16/fog-mirror)** - a steamy bathroom mirror in the browser that you wipe clear with your hand, using the webcam. One HTML file. [Try it](https://fog-mirror-atharv.netlify.app)

Some of my other work, like a private photo and video storage app, lives in private repositories.
